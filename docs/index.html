NAI Launcher 是开源、跨平台的第三方 NovelAI 客户端，连接 Prompt 编写、图像生成与编辑、资源整理和可选的云备份。

项目不运营用于托管 NovelAI 账号或用户作品的自有服务器。Google Drive 连接只访问隐藏的应用数据目录；OneDrive 连接只访问应用专属文件夹。

本地优先

Prompt、图库索引、标签和 Agent 会话默认保存在设备上。

明确同步

只有用户主动选择的数据范围，才会在用户明确操作后上传或拉取。

开放透明

客户端以 MIT License 开源，功能边界和数据去向可以公开检查。

云备份如何工作

连接 Google Drive 或 OneDrive 时，NAI Launcher 会打开服务商的官方登录页面。OAuth access token 和 refresh token 保存在设备安全存储中，不会写入备份。

备份只在用户明确点击上传、拉取或恢复后传输；内容使用明文快照，因此用户应自行确认所选云端账号和存储空间的访问安全。

Google Drive 仅使用 drive.appdata 对应的应用专属数据目录；OneDrive 仅使用 Files.ReadWrite.AppFolder 对应的应用文件夹。应用不会请求扫描普通网盘文件。

支持与政策

连接云盘前，请先阅读我们的 隐私政策 与 服务条款。如果遇到问题，可在 GitHub Issues 提交反馈。

English summary

NAI Launcher is an open-source, cross-platform, third-party NovelAI client. Local data stays on your device by default. Google Drive accesses its hidden app-data directory, while OneDrive accesses an app-specific folder. Only the data categories you explicitly select are transferred when you start an upload, download, or restore.

Read the Privacy Policy and Terms of Service before connecting a cloud account.
